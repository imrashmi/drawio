Fork Info

This is the last supported version of Draw.io with Visio (VSDX) support.

As there's no where else I could find hosting this easily online, I have forked Draw.io at this version.

This means you can browse to https://mattie47.github.io/drawio/src/main/webapp/ and then export your drawio diagram to Visio again 🙌

Note: This is purely a fork of draw.io. I won't make any changes, updates, or provide any support.

Instead of running via GitHub Pages, you can also download the last supported desktop version:
https://github.com/jgraph/drawio-desktop/releases/tag/v26.0.16

About

draw.io is a configurable diagramming/whiteboarding visualization application jointly developed by JGraph Ltd and draw.io AG.

A production-grade deployment is available at: https://app.diagrams.net

Scope of the Project

draw.io is a diagramming/whiteboarding tool, not an SVG editor. SVG export is intended for embedding, not editing.

This project is provided as-is and is not intended as a development framework.

Alternatives:

  • Tldraw
  • Excalidraw

Collaborative editing is not supported.
